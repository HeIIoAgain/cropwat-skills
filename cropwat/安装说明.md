# cropwat — 驱动 CROPWAT 8.0 测算

用 DSH 代理驱动 FAO **CROPWAT 8.0** 批量计算作物需水量，输出结果 Excel。

**这个文件夹本身就是一个完整的 DSH 技能。**

---

## 安装到 DSH

把**本文件夹整个**复制到 DSH 的技能目录，文件夹名保持 `cropwat`：

```powershell
# 默认位置（$DSH_HOME 未设置时）
Copy-Item -Recurse -Force ".\cropwat" "$env:USERPROFILE\.dsh\skills\cropwat"

# 若设了 DSH_HOME
Copy-Item -Recurse -Force ".\cropwat" "$env:DSH_HOME\skills\cropwat"
```

**只对某个项目生效**：放到项目根的 `.dsh\skills\cropwat\`（项目根 = 含 `.git` 的最近祖先目录）。

DSH 会热加载技能，通常无需重启；新会话里看不到就重启一次。

---

## 前置条件

| 条件 | 说明 |
|---|---|
| Windows | CROPWAT 8.0 是 Win32 GUI 程序 |
| CROPWAT 8.0 已安装 | **位置不用指定**，程序会自动查找（注册表 → 环境变量 → 常见目录 → 磁盘扫描 → PATH） |
| Python 3.9+ | DSH 自带运行时即可；需要 `openpyxl` |
| 完整文件/注册表权限 | CROPWAT 启动要写注册表；权限不足会报 `Localizer Error` |

## 用之前先备好工作目录

本技能只负责**跑模型**，不负责造输入文件。工作目录需要长这样：

```
<工作目录>\
├── Climate\<地点>\<地点>_<年份>.PEM
├── Rain\<地点>\<地点>_<年份>.CRM
├── Crop\<作物>.CRO
└── Soil\<土壤>.SOI          （或直接放根目录）
```

**这些文件用配套技能 `cropwat-inputs` 生成**（查它的 `build` / `crops` / `soil` 三个命令）。

## 运行

```powershell
python cropwat_run.py check --data "<工作目录>"     # 先扫描，不启动 CROPWAT

python cropwat_run.py run `
  --data    "<工作目录>" `
  --sowing  "WHEAT=05/05,MAIZE=25/04,RICE=10/05" `
  --years   2013 2014 2015 2016 2017 2018 2019 2020 2021 2022 2023 2024 `
  --cities  呼和浩特 包头 乌海 赤峰 通辽 鄂尔多斯 呼伦贝尔 巴彦淖尔 乌兰察布 兴安盟 锡林郭勒 阿拉善 `
  --crops   WHEAT MAIZE RICE POTATO SOYBEAN SUNFLOWR GRONDNUT `
  --crop-names "WHEAT=小麦,MAIZE=玉米,RICE=水稻,POTATO=马铃薯,SOYBEAN=大豆,SUNFLOWR=向日葵,GRONDNUT=花生"
```

**五项参数必填**：工作文件位置、播种日期（DD/MM）、时间范围、地点范围、作物范围。
**结果表格不用指定** —— 自动写到桌面 `cropwrt计算结果.xlsx`。

先预览不加 `--dry-run` 的那一步：加 `--dry-run` 只打印参数摘要、组合数和用时估算，不启动 CROPWAT。

### 运行时长

**每组约 85 秒**。预计总用时 = 地点数 × 作物数 × 年数 × 85 秒。
例：12 地点 × 7 作物 × 12 年 = 1008 组 ≈ **23.8 小时**。

### ⚠ 测算期间请勿使用键盘和鼠标

程序通过**模拟鼠标点击和按键**操作 CROPWAT。任何人工输入、窗口切换、弹窗遮挡都会干扰它，
可能导致该组结果错误甚至失败。**请离开电脑，或至少不要动键鼠。**

**中断也没关系**：结果逐组落盘，重新执行同一条命令即可自动跳过已完成的组。

## 结果表格

桌面上的 `cropwrt计算结果.xlsx`，三个工作表：

| 工作表 | 内容 |
|---|---|
| 宽表(地方×年份) | 一行一个"地方-年份"，**同一地方的年份相邻**；每种作物三列 `ETc(mm)` / `Eff(mm)` / `Irr(mm)` |
| 长表(面板格式) | 地方 / 作物 / 年份 / 播种期 / ETc / Eff / Irr，一行一个观测，可直接做面板回归 |
| 说明 | 数据来源、指标定义、绿水蓝水公式、单位换算、各作物所用播种期 |

| 指标 | 含义 |
|---|---|
| ETc | 作物需水量（mm），生育期累计 |
| Eff | 有效降水量（mm） |
| Irr | 灌溉需水量（mm）；即蓝水足迹 |
| 绿水足迹 | Σ min(ETc, Eff) |
| 单位换算 | 1 mm × 1 ha = 10 m³ |

中间文件（汇总 CSV、每组结果）在 `~\.cropwat_run`，不占桌面。

## 配套技能

- **`cropwat-inputs`** —— 造输入文件（`.PEM` / `.CRM` / `.CRO` / `.SOI`，FAO-56 算 ETo）
- **`cropwat`**（本文件夹）—— 驱动测算

---

## 最容易踩的坑

| 坑 | 后果 |
|---|---|
| **播种期必须写进 Crop 模块** | 写进「种植模式(Cropping Pattern)」模块对 CWR 计算**完全无效**，结果照常返回、只是用了错的播种期 |
| **调用顺序：先载作物，再设日期** | 载入 `.CRO` 会重置播种期 |
| **播种期格式是 DD/MM（日/月）** | 5月5日 = `05/05`，4月20日 = `20/04` |
| **不能靠程序读回播种期** | 那个 Delphi 掩码框永远返回 `__/__` |
| **菜单命令必须先让主窗口前台** | 否则静默无效，不报错 |
| **土壤文件不影响 CWR** | 只有"灌溉排程"模块才用它 |

`SKILL.md` 里有完整的坑位清单和验证方法。
